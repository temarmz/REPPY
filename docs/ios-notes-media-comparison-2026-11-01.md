# Заметки и видеоинструкции — 1 ноября 2026

Веб остаётся эталоном состава экранов. Сверены дневник, выбор дня, просмотр инструкции обеих ролей и редактор инструкции тренера в светлой и тёмной теме. Эталоны сняты из текущей production-сборки веба, Chrome 393 × 852, ru-RU, Europe/Moscow; каждое состояние открывается в отдельном контексте браузера. Нативные снимки получены UI-тестами на iPhone 16, iOS 18.3.1. Данные заметок сохраняются между нативными прогонами; выбранная дата календаря и введённые тексты на сравнении могут различаться.

## Изменения

| Область | Результат в iOS |
| --- | --- |
| Навигация дневника | «Сегодня» рядом с заголовком; стрелки и диапазон в одной группе. Минимальная высота 48 pt, высоты группы совпадают. Внутри месяца диапазон сокращён, сохраняя даты и год |
| Карточка дня | Дата, «Сегодня» или день недели, обычный текст и «Запиши здесь…». Четыре дня в сетке 2 × 2; accessibility-размеры используют одну колонку. Отступы, минимальная высота и шрифт получаются из веб-токенов |
| Ввод и статусы | Нативный TextEditor с независимой прокруткой, высота не зависит от клавиатуры. Под статус зарезервировано постоянное место; сохранение не сдвигает текст. Ошибка и конфликт предлагают разные действия. Лимит 50 000 знаков сохранён |
| Выбор дня | Пояснение о четырёх днях, точки у непустых записей с учётом черновиков, явное возвращение к сегодня. Выбор даты закрывает окно. Accessibility-подпись говорит о заметке, а не о тренировках |
| Диапазон и хранение | Выбранная дата хранится отдельно для аккаунта. Нажатие таба «Заметки» возвращает к сегодня, включая повторное нажатие. Уход из поля отправляет сохранение сразу. До первоначальной загрузки поле не редактируется; повреждённый файл диапазона не блокирует доступ к тексту дневника |
| Просмотр инструкции | Медиаблок, состояние отсутствующего видео, имя/размер сохранённого файла, оборудование, «Как выполнять», текст или пустое состояние как в вебе. Подписанный URL загружается при открытии; ошибки получения URL и AVPlayerItem предлагают повтор |
| Редактор инструкции | Отдельный нативный sheet вместо раскрывающегося блока. Локальный текст, выбранное/удалённое видео и явное «Сохранить инструкцию». Текст до 1500 знаков восстанавливается из защищённого черновика аккаунта. Изменения применяются к плану после успешного сохранения, загрузка файла начинается по этому действию |
| Видео | Системный выбор файла и камера на поддерживаемом устройстве; проверка формата, пустого файла и 100 МБ перед предпросмотром. Размер/имя выбранного файла, замена и удаление ссылки из инструкции. Общий VideoPlayer использует компактную область 16:9 и системные элементы воспроизведения |

Поздний ответ загрузки проверяет время жизни окна и ID упражнения, прежде чем применять результат к binding. Закрытие окна не заменяет видео у другого упражнения. Предпросмотр держит security-scoped доступ к локальному файлу на время использования и останавливает плеер при закрытии. Удаление видео из инструкции не удаляет объект, который может использоваться другим снимком тренировки.

Новые компоненты NotesHeader, InstructionMedia, InstructionEquipment и InstructionEditor зарегистрированы в каталоге; состояния заметок и медиа показаны в дизайн-ките. Редактор открывается из существующего примера ExerciseEditorCard. Сервер, RLS, таблица trainer_notes и RPC save_trainer_note не менялись. Демо не загружает видео в Supabase.

Изменения общей навигации проверены отдельно, её код одинаков для обеих ролей.

Запись камерой, реальная загрузка и воспроизведение MOV/MP4/WebM, Storage RLS, истечение подписанного URL, синхронизация заметок между вебом и iOS, потеря сети/ответа и конфликт двух рабочих аккаунтов требуют отдельной интеграционной приёмки. Этот этап не создавал и не изменял рабочие записи или файлы в Supabase. Прохождение демо-сценариев не подтверждает эти проверки.
