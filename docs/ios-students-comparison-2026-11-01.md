# Сверка учеников и назначения — 1 ноября 2026

Этап охватывает список учеников, профиль активного ученика, выбор предыдущей тренировки и редактор новой/повторной тренировки. Веб-эталоны сняты в Chrome, 393 × 852, обе темы, ru-RU, Europe/Moscow, локальное демо. iOS — тот же демо-контракт, iPhone 16/iOS 18.3.1. Проверки не обращаются к рабочим аккаунтам.

| Экран | Подтверждённое отличие | Исправление |
| --- | --- | --- |
| Ученики | Лишний заголовок, нейтральное приглашение, вложенная кнопка открытия, другой порядок имён | Основное приглашение сверху; вся карточка открывает профиль; аватар, ближайшее назначение/последнее завершение и баланс; порядок общего набора данных |
| Небольшой список | Постоянное поле поиска занимало место, которого нет в вебе | Поиск показывается для списка больше восьми учеников; отдельное сообщение при отсутствии совпадений |
| Данные ученика | Рост, вес и телефон отдельными строками, без пола | Компактная общая строка данных с полом, ограничения ниже, нативная кнопка редактирования |
| Профиль | Абонемент и история раньше предстоящих занятий; имя ученика повторялось в заголовках тренировок | Данные/прогресс → расписание и назначение → абонемент → последняя активность; строки расписания называют тренировку |
| Абонемент тренера | Отдельный дизайн, нет последнего пополнения | Общая сводка обеих ролей; у тренера одно последнее пополнение и действия продления/истории |
| Назначение | Из профиля сразу открывался пустой редактор | Выбор прошлых назначений, завершённые первыми; восемь видимых записей и раскрытие остальных; создание с нуля или повторение |
| Редактор | Повторный выбор уже известного ученика, формат в выпадающем меню | Контекст ученика с аватаром; нативный сегмент «Очно / Онлайн»; у онлайн нет поля времени; имя новой тренировки пустое, назначение без имени недоступно |

Повторение использует существующий `WorkoutExecution.planFromActual` и новые идентификаторы упражнений; исходная история сохраняется. При восстановлении черновика из контекстного входа выбранная связь ученика закрепляется за контекстом экрана. Сохранение данных ученика теперь обновляет его на прежнем месте массива, чтобы редактирование не перемещало карточку в конец списка.

У приглашённого ученика скрыты назначение и абонемент, показано ожидание подключения и существующее действие создания новой ссылки. Полная сверка приглашений и удаления приглашённого ученика остаётся отдельной задачей: демо не создаёт реальные приглашения. Эталон страницы приглашения снят, но сценарий её отправки этим этапом не принимается.

Новые общие компоненты `StudentLink`, `StudentContext`, `FormatPicker` внесены в каталог и дизайн-кит. Основные NavigationLink используют общий центрированный label с иконкой. Нативные сегменты, дата/время, возврат и Dynamic Type сохраняются; точное совпадение шрифта и координат с браузером не заявляется.
