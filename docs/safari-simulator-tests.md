# Safari в iPhone Simulator

Запускать поверх локального демо, без рабочей авторизации и Supabase. Перед тестом открыть демо и войти через «Попробовать REPPY». Перед повторным полным прогоном сбросить демо через профиль, чтобы роль снова стала trainer. Preview — `npm run build:pages`, затем `npm run preview -- --host 127.0.0.1 --port 4173`.

```
xcrun simctl list devices available
python3 scripts/run-safari-simulator-tests.py --device 75979B57-C9B9-49FF-8868-091575FDB899
```

Runner собирается в `work/safari-e2e` и управляет настоящим Safari через XCUITest. Нативный клиент REPPY не изменяется. Результат `.xcresult` содержит снимки, запись экрана и журнал действий. Тест использует локальное демо и дописывает тестовый текст в заметки.

Первый сценарий: 8 кругов по четырём табам тренера и профилю в шапке, быстрый свайп перед каждым касанием, действия диапазона заметок : 64 активации. Второй: 5 кругов по трём табам ученика и профилю в шапке, переключение месяцев, все четыре текстовых поля и закрытие клавиатуры. На каждое действие отправляется одно tap; ожидание появления экрана не повторяет касание. XCTest самостоятельно ожидает quiescence приложения: этот прогон не доказывает отсутствие любой задержки при произвольной скорости касаний на физическом устройстве.

Это проверка основных потоков и повторных переходов, не исчерпывающий перебор всех кнопок во всех возможных состояниях. Ошибки, модальные состояния и дополнительные формы также проверяются Playwright-тестами WebKit/Chrome.
