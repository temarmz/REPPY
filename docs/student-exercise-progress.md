# ТЗ: Прогресс по упражнениям — MVP

Статус: реализовано и включено в локальную ветку `main`.
Актуальная редакция: 9 сентября 2026 года. Заменяет предыдущие варианты с отдельной сводкой, поиском, периодами и таблицей.

## Задача

Тренер открывает ученика и сразу видит результаты упражнений. Одно нажатие на упражнение открывает динамику за всю историю. Интерфейс показывает факты, не оценивает автоматически рост силы или качество тренировки.

## Профиль ученика

Внизу профиля ученика в кабинете тренера находится раздел «Прогресс по упражнениям». Данные и ограничения ученика показаны мелким текстом сразу под именем, рядом — иконочная кнопка с карандашом. Карандаш открывает форму с сохранением и отменой; ограничения не скрываются за раскрытием.

- Используются обычные строки списка приложения с шевроном.
- Строка содержит название и сравнение лучших подходов двух последних занятий: «Было → Стало».
- Лучший подход для внешнего веса — максимальный вес, затем максимум повторений при этом весе. Для собственного веса и времени — максимум повторений/секунд. Вес и повторения берутся из одного реального подхода.
- Короткая подпись показывает фактическую разницу: «+2,5 кг при тех же повторах», «+2 повт.», «+5 кг, −3 повт.» или «Без изменений». При единственном занятии остаётся только результат без подписи и индикатора.
- Рост без ухудшения другого показателя выделяется лаймовым, спад без улучшения другого — оранжевым. Без изменений и смешанная динамика показаны серым. Цвет применяется только к тексту изменения; дополнительные стрелки не используются. Обычный шеврон открывает график. Сравнение не учитывает увеличение числа подходов и не является оценкой роста силы.
- Даты и все выполненные подходы находятся внутри графика. Каждый подход там записывается одинаково: `1. 80 кг × 8 повт.`, `2. 80 кг × 7 повт.`. Если выполнена только часть подходов, показывается одна подпись «Выполнено 2 из 4».
- Упражнения сортируются по последнему выполнению. Разные режимы одного упражнения имеют отдельные строки с уточняющей подписью.
- Если результатов нет, показывается короткое сообщение без дополнительных действий.

Отдельный экран сводки, поиск и фильтры не нужны. Старый адрес `/trainer/clients/:studentId/progress` открывает профиль с этим разделом.

## Экран упражнения

1. Общий заголовок приложения: стандартная кнопка «Назад», имя ученика и название упражнения.
2. Подпись «Всё время · N занятий», без выбора периода.
3. Один график с явно подписанной метрикой.
4. Выбранное занятие: дата, значение метрики и выполненные подходы.
5. Обычная вторичная кнопка «Открыть тренировку».

| Режим | Метрика |
| --- | --- |
| Внешний вес и повторения | Максимальный вес выполненного подхода, кг |
| Собственный вес и повторения | Максимум повторений в выполненном подходе |
| Время | Максимальная длительность выполненного подхода, секунды |

Таблицы, выбора метрики, селектора упражнения и раскрытия плана/комментариев на этом экране нет. Полный контекст уже доступен в результате тренировки; дублировать его не нужно.

График показывает все завершённые занятия с валидными результатами. Даты расположены по времени, без нулевых точек в дни без занятий. Точку можно выбрать касанием или клавиатурой. Стрелки переключают соседние занятия, включая совпадающие по времени точки. При нескольких занятиях в один день рядом с датой появляется время. Для единственной точки показывается пояснение, что для динамики нужно ещё одно занятие.

«Назад» возвращает в источник перехода. При возврате в профиль раздел прогрессии прокручивается в видимую область. Для прямой ссылки запасной маршрут — профиль ученика.

## Дополнительные входы

- В результате завершённой тренировки — «Прогресс упражнения» у упражнения с историей.
- В назначенной тренировке тренера — такая же ссылка, если по упражнению уже есть результаты. Это позволяет проверить прошлую нагрузку перед занятием.
- Ссылок в общем справочнике упражнений нет: там не выбран ученик.

Эти входы сразу открывают график нужного упражнения нужного ученика. Новые элементы главной навигации не добавляются.

## Данные

- Источник — завершённые `WorkoutSession` конкретного ученика и их `workoutSnapshot`. Текущие планы назначений не участвуют в чтении исторических результатов.
- `SetResult.exerciseId` связывается с `WorkoutExercise.id` внутри снимка. Между сессиями группировка идёт по идентификатору справочника `WorkoutExercise.exerciseId`, режиму нагрузки и типу измерения.
- Повтор одного упражнения в одной сессии образует одну точку с отдельными блоками подходов.
- Учитываются только отмеченные выполненными подходы с конечным положительным количеством повторений/секунд и конечным неотрицательным внешним весом. Ноль кг допустим.
- Незавершённые и некорректные подходы не входят в сводку и метрики. Их исходные записи остаются в результате тренировки.
- Дата — `completedAt`; будущие и некорректные даты не отображаются. Незавершённые сессии исключаются.
- Старые параметры `period`, `view`, `metric`, `q` больше не влияют на экран. Параметры режима нагрузки и измерения сохраняют различие вариантов упражнения.
- Изменение назначенной тренировки не меняет уже записанную прогрессию. Завершение или удаление сессии сразу меняет вычисляемое представление.
- Новая схема хранения, миграция и backend не нужны. Данные остаются в существующем repository/localStorage.

## Единый интерфейс

Заголовок и кнопка «Назад» используют общий компонент `app/page-header.tsx`. Список, вторичные кнопки, шрифты и цвета используют существующие классы и переменные приложения. Текст действий использует единый размер `--button-font-size: 14px` на всех ширинах; иконки и вспомогательные данные карточек имеют собственные размеры. Специальные стили ограничены графиком и компактным представлением подходов.

Карандаш под именем открывает и закрывает форму характеристик. Повторное нажатие закрывает форму без сохранения, как «Отмена». При следующем открытии поля снова содержат сохранённые значения.

## Проверки

- Профиль → график за одно нажатие, возврат в профиль и вход из назначения/результата.
- Вся история отображается даже при старой ссылке с фильтрами; данные учеников не смешиваются.
- Единственная точка, отсутствие результатов, неизвестный режим, новое завершённое занятие.
- Клавиатура и стрелки выбора занятия; переход к полному результату.
- Мобильный экран 360 px и широкий экран 1280 px без горизонтального переполнения.
- Стили «Назад» совпадают со стилями этой кнопки в профиле.
- `npm test`, `npm run lint`, `npm run typecheck`, `npm run test:e2e` (включает production-сборку).
