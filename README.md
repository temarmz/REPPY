# REPPY — Prototype V0

Интерактивный mobile-first прототип сервиса для персонального тренера и его учеников.

Главный сценарий работает целиком внутри одного браузера: тренер создаёт тренировку, назначает её ученику, ученик выполняет подходы и записывает фактические результаты, после чего тренер видит завершённую сессию.

## Запуск

```bash
npm install
npm run dev
```

Единственная production-сборка для проверки и публикации на GitHub Pages:

```bash
npm run build:pages
```

Статическая GitHub Pages-версия создаётся в `pages-dist`. Hash-маршруты работают после прямого reload, а workflow `.github/workflows/deploy-pages.yml` публикует папку автоматически из ветки `main`.

## Демо-данные

Состояние хранится в `localStorage` текущего браузера. Компактный переключатель `DEMO` меняет роль без сброса данных. В настройках доступно восстановление исходного seed.

Рабочее название всех экранов прототипа — **REPPY**.
